# AI商业分析顾问项目

## 1. 项目简介

本项目是一个基于 Python、Pandas、Streamlit 和 DeepSeek API 开发的 AI 商业分析顾问系统。用户可以上传 Excel 数据文件，并通过自然语言输入业务问题，系统会自动读取数据、生成数据摘要，并调用 DeepSeek API 输出商业分析建议。

该项目主要用于模拟企业经营分析场景，支持对销售额、利润、订单数、客户数、地区、品类、子品类和折扣等维度进行智能分析，帮助用户快速发现经营问题并提出优化方案。

本项目适用于数据分析师、商业数据分析师、AI数据分析师、AI应用开发等岗位作品集展示。

---

## 2. 项目目标

- 实现 Excel 数据上传与自动读取
- 自动生成数据摘要
- 支持用户输入自然语言业务问题

- 自动生成经营诊断、问题分析和优化建议
- 展示 AI 在商业数据分析和经营决策支持中的应用能力

## 4. 项目功能

### 4.1 Excel 数据上传

用户可以上传 `.xlsx` 或 `.xls` 格式的数据文件，系统会自动读取数据并展示前 5 行数据预览。

### 4.2 自动生成数据摘要

系统会根据上传的数据自动生成摘要，包括：

- 数据行数
- 字段数量
- 字段名称
- 总销售额
- 总利润
- 整体利润率
- 总订单数
- 总客户数
- 总销量
- 销售额最高地区
- 销售额最低地区
- 销售额最高品类
- 利润最低品类
- 利润最低子品类
- 高折扣订单利润率

### 4.3 自然语言业务提问

用户可以输入业务问题，例如：

- 请分析这个数据的整体经营情况，并指出主要问题。
- 为什么利润率偏低？应该如何优化？
- 哪个地区最值得重点投入？
- 高折扣订单是否影响利润？
- 哪些品类或子品类存在经营风险？

### 4.4 AI 商业分析建议生成

系统会将用户问题和数据摘要发送给 DeepSeek API，生成商业分析建议，内容包括：

- 整体经营情况分析
- 核心经营问题诊断
- 潜在业务原因分析
- 可执行优化建议
- 经营决策参考

## 6. 典型分析结果

基于 Superstore Sales 数据集，系统可以识别出以下经营问题：

### 6.1 家具品类利润表现较弱

系统分析发现，Furniture 品类整体利润率偏低，主要受到 Tables 和 Bookcases 等子品类亏损影响。

### 6.2 高折扣订单影响利润

系统识别出折扣大于等于 0.3 的订单整体利润率为负，说明企业存在过度折扣问题，应加强折扣审批和利润管控。

### 6.3 区域发展不均衡

系统可以识别不同地区销售额差异，并分析销售额最高地区和最低地区之间的经营差距，为区域资源投入提供参考。
