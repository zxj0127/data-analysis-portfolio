# 电商用户行为分析项目

## 1. 项目简介

本项目基于 Online Retail 电商交易数据集，围绕电商平台用户行为、商品销售表现、月度销售趋势和用户价值分层展开分析。

项目使用 Python/Pandas 完成数据清洗、缺失值处理、退货订单剔除和销售额字段构建，并基于 RFM 模型对用户进行价值分层，识别高价值用户、流失风险用户、重点发展用户、重点唤回用户和一般用户，最终提出差异化用户运营策略。

本项目适用于数据分析师、商业数据分析师、BI分析师等岗位作品集展示。

---

## 2. 项目目标

- 完成电商交易数据清洗与预处理
- 分析核心业务指标：销售额、订单数、客户数、客单价
- 分析商品销量与销售额排行
- 分析月度销售趋势
- 基于 RFM 模型完成用户价值分层
- 针对不同用户群体提出运营策略

---

## 3. 数据说明

本项目使用 Online Retail 公开数据集。

原始数据规模：

- 原始数据：541,909 条记录
- 清洗后有效数据：392,692 条记录
- 有效订单数：18,532 单
- 有效客户数：4,338 人
- 总销售额：9,747,747.93
- 客单价：526.00

主要字段说明：

| 字段 | 含义 |
|---|---|
| InvoiceNo | 订单编号 |
| StockCode | 商品编号 |
| Description | 商品名称 |
| Quantity | 购买数量 |
| InvoiceDate | 订单时间 |
| UnitPrice | 商品单价 |
| CustomerID | 客户ID |
| Country | 国家 |
| SalesAmount | 销售额 |
