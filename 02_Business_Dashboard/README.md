# 销售经营分析平台项目

## 1. 项目简介

本项目基于 Superstore Sales 销售数据集，围绕企业销售经营情况展开分析，重点分析销售额、利润、订单数、客户数、客单价、地区表现、品类表现、商品销售排行、月度销售趋势以及经营问题诊断。

项目使用 Python/Pandas 完成数据清洗、核心指标计算、经营分析和可视化图表生成，并针对 Furniture 品类利润率低、Central 地区利润率低、高折扣订单亏损等问题提出优化建议。

本项目适用于数据分析师、商业数据分析师、BI工程师、经营分析实习生等岗位作品集展示。

---

## 2. 项目目标

- 完成销售数据清洗与预处理
- 计算核心经营指标：销售额、利润、订单数、客户数、客单价、利润率
- 分析不同地区销售额和利润表现
- 分析不同品类销售额、利润和利润率
- 分析销售额 TOP10 商品
- 分析月度销售趋势
- 诊断低利润品类和低利润地区的原因
- 分析折扣对利润率的影响
- 提出经营优化建议

---

## 3. 数据说明

本项目使用 Superstore Sales 公开销售数据集。

数据规模：

- 原始数据：9,994 条记录
- 字段数量：21 个
- 总销售额：2,297,200.86
- 总利润：286,397.02
- 总订单数：5,009
- 总客户数：793
- 总销量：37,873
- 客单价：458.61
- 利润率：12.47%

主要字段说明：

| 字段 | 含义 |
|---|---|
| Order ID | 订单编号 |
| Order Date | 订单日期 |
| Ship Date | 发货日期 |
| Ship Mode | 发货方式 |
| Customer ID | 客户编号 |
| Customer Name | 客户名称 |
| Segment | 客户类型 |
| Region | 地区 |
| Category | 产品品类 |
| Sub-Category | 产品子品类 |
| Product Name | 商品名称 |
| Sales | 销售额 |
| Quantity | 销量 |
| Discount | 折扣 |
| Profit | 利润 |
