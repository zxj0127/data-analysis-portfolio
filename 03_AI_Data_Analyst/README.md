# AI数据分析助手项目

## 1. 项目简介

本项目是一个基于 Python、Pandas、Streamlit 和 DeepSeek API 开发的 AI 数据分析助手。用户可以上传 Excel 文件，系统自动完成数据预览、基础信息统计、业务指标计算、可视化图表生成，并调用 DeepSeek API 自动生成数据分析报告和业务优化建议。

该项目主要面向数据分析师、商业数据分析师、AI数据分析师等岗位作品集展示，体现“数据分析 + AI自动化”的综合能力。

---

## 2. 项目目标

- 实现 Excel 文件上传与数据读取
- 自动展示数据预览和数据基本信息
- 自动统计缺失值情况
- 自动识别数值型字段并生成描述统计
- 自动计算销售额、利润、订单数、客户数、客单价、利润率等业务指标
- 自动生成地区销售额、品类销售额、月度销售趋势、TOP10商品等可视化图表
- 自动生成规则版数据分析结论
- 接入 DeepSeek API，生成完整 AI 数据分析报告

## 4. 项目功能

### 4.1 Excel 文件上传

用户可以上传 `.xlsx` 或 `.xls` 格式的数据文件，系统自动读取数据并展示前 5 行数据预览。

### 4.2 数据基本信息统计

系统自动输出：

- 数据行数
- 字段数量
- 字段缺失值情况
- 数值型字段描述统计

### 4.3 自动业务指标分析

当数据中存在相关字段时，系统可以自动计算：

| 指标 | 说明 |
|---|---|
| 总销售额 | 根据 Sales 字段汇总 |
| 总利润 | 根据 Profit 字段汇总 |
| 总订单数 | 根据 Order ID 去重统计 |
| 总客户数 | 根据 Customer ID 去重统计 |
| 总销量 | 根据 Quantity 字段汇总 |
| 客单价 | 总销售额 / 总订单数 |
| 利润率 | 总利润 / 总销售额 |

### 4.4 自动可视化分析

系统可自动生成以下图表：

- 各地区销售额对比图
- 各品类销售额对比图
- 月度销售额趋势图
- 销售额 TOP10 商品图
- 数值型字段分布图

### 4.5 自动分析结论

系统基于业务指标自动生成初步分析结论，例如：

- 总销售额情况
- 总利润情况
- 整体利润率情况
- 销售贡献最高地区
- 销售贡献最高品类
- 高折扣订单利润率情况
- 折扣策略优化建议

### 4.6 DeepSeek API 生成分析报告

用户在左侧输入 DeepSeek API Key 后，可以点击按钮生成 AI 数据分析报告。

AI 报告内容包括：

- 整体经营情况总结
- 主要业务亮点
- 潜在经营问题
- 可执行的优化建议
